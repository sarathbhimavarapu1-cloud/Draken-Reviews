# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues. Contact the repository owner privately through the contact options on the GitHub profile and include:

- A clear description of the issue and its potential impact
- Reproduction steps or a proof of concept
- Any suggested mitigation

## Safe use

- Never commit API keys, tokens, passwords, or other secrets.
- Configure AI provider credentials as server-side environment variables.
- Do not submit secrets or proprietary source code unless you have permission and have reviewed the configured AI provider's data-handling terms.
- AI-generated findings are advisory. Validate them with tests and human review.
- Before using this MVP with public traffic, add authentication, rate limiting, usage controls, and monitoring.
